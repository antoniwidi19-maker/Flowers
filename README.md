# 🌸 Keindahan Dunia Bunga 3D

Website sederhana yang menampilkan daftar berbagai jenis bunga beserta deskripsinya, dilengkapi dengan animasi objek **3D interaktif** menggunakan library **Three.js**.

## 📁 Struktur File
Pastikan semua file berikut berada di dalam satu folder yang sama:
- `index.html` : Kerangka utama website.
- `style.css` : File styling untuk mempercantik tampilan.
- `script.js` : Logika animasi dan interaksi objek 3D menggunakan Three.js.
- `README.md` : Dokumentasi project.

## 🚀 Cara Menjalankan
1. Pastikan Anda memiliki browser modern (Chrome, Edge, Firefox, dll).
2. Simpan keempat file di atas ke dalam satu folder baru.
3. Klik dua kali pada file **`index.html`** untuk membukanya di browser.

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **CSS3 (Flexbox & Grid)**
- **JavaScript (ES6)**
- **Three.js** (via CDN untuk render 3D)
